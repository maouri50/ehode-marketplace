# Ehode first collection plan

## Recommendation

Ehode should launch with a **focused teacher and classroom-organisation collection** rather than a broad mix of unrelated printables. The first customer is a time-poor teacher, tutor, or homeschool parent who wants a usable system immediately, not another individual decorative page.

This is a practical fit for the storefront’s current visual direction and the school-oriented resources already appearing in its catalog. It also makes it easier to build bundles, cross-sell related files, and describe clear outcomes. The proposal is not a guarantee of revenue; it is a lower-complexity way to test an audience and learn what shoppers buy.

> **Positioning:** “Calm, practical teacher tools for planning, parent communication, and classroom routines.”

Etsy’s marketplace page identifies planners and business guides as prominent digital-download categories, while Etsy’s trend reporting emphasizes personal usefulness, experience, and a distinct shop story rather than generic inventory. [1] [2]

## What to sell first

| Priority | Product | Buyer result | Recommended introductory price* | Format |
|---|---|---|---:|---|
| 1 | Weekly Teacher Planning Pack | A repeatable weekly lesson and task system | $9–14 | Printable PDF + editable original template link |
| 2 | Parent Communication Kit | Faster messages for absences, reminders, praise, and meetings | $6–10 | PDF + editable original template link |
| 3 | Substitute Teacher Emergency Folder | A ready-to-print pack for an unexpected absence | $8–13 | Print-ready PDF |
| 4 | Student Homework & Reading Tracker | A simple, family-friendly tracking tool | $3–6 | Printable PDF |
| 5 | Classroom Reward & Routine Cards | A coherent routine system, not isolated clipart | $5–9 | Print-ready PDF |
| 6 | Tutor Session Planner | A repeatable intake, lesson, and progress workflow | $5–9 | PDF + editable original template link |

\*These are starting price hypotheses, not market-price claims. Test them with a limited launch offer and revise after genuine visitor and purchase data.

## The first paid bundle

Make the **Teacher Calm Week Bundle** the flagship product at **$18–24**. It should include the first five resources above, a one-page “start here” guide, and two seasonal color versions. This is stronger than selling six disconnected files because buyers can understand the outcome in one sentence: plan the week, communicate with families, and run routines with less preparation.

## A simple ten-listing launch order

| Week | Listings | Purpose |
|---|---|---|
| 1 | One free weekly checklist, one paid planner, one parent-message kit | Build a useful free entry point and validate the core problem |
| 2 | Substitute folder, reading tracker, reward cards | Add low-price discovery products |
| 3 | Tutor planner, bundle, two bundle color/style variants | Create higher-value choices and a clear collection |
| 4 | Improve only the listings shoppers actually open, save, or buy | Avoid creating more inventory without evidence |

Use the free weekly checklist as the visible lead resource. Its product page should point to the paid planner and the bundle. Do not add email marketing automatically; the existing store delivery email should remain transactional only unless a buyer separately opts in.

## What to avoid at launch

Avoid generic “50,000 prompts,” random wall-art packs, copied marketplace designs, unlicensed character content, and isolated stock clipart. These are difficult to differentiate and can create licensing risk. If using Canva, each sellable item must be an original design rather than standalone Canva content. Canva also requires templates containing Pro content to be supplied as Canva template links, not exported editable files; digital clipart for external use must be created from scratch rather than Canva library elements. [3]

## Listing formula for every resource

Each product should have a short outcome-first title, five preview images, a clear file list, software requirements, and a simple license statement. Use preview images that show the resource in use: a filled planner spread, a parent-message example, or a printed classroom card sheet. The first image should communicate the buyer’s outcome in under two seconds.

| Listing element | Example for the planner pack |
|---|---|
| Outcome-first title | “Weekly Teacher Planner Pack — Lesson, Task & Parent Communication System” |
| First image | One clean, completed weekly spread with three labelled benefits |
| Included files | PDF print file, A4 and US Letter sizes, editable original-template link if included |
| Buyer fit | “For primary teachers, tutors, and homeschool planners” |
| License | “Personal/classroom use for one educator. No resale, redistribution, or template sharing.” |

## Decision rule after the first month

Do not expand into a second category until one of the first three paid products has either consistent purchases or repeated add-to-basket interest. If the free checklist is downloaded but the planner is not purchased, improve the bundle promise and preview images before making more files. If parent communication sells better than planning, make the next collection around family communication rather than forcing the original plan.
